# todo-list-web-app
A small to-do list made for Web Engineering course using HTML, CSS and JavaScript.

## How to use
1. Open the `todo.html` file in any browser
2. Type your task in the box
3. Click Add
4. Click on the task to mark it completed
5. Click Delete if you want to remove it

Tasks are saved in the browser so they don't disappear when you refresh the page.

## Features
- Add new tasks
- Mark tasks as complete
- Delete tasks
- Local storage (so data stays)

That's pretty much it. Just a basic project.
